## One-paragraph pitch

Candidate direction (from the 2026-09-14 lit review, pending Taylor's sign-off): dopants and
defects set the properties DoD systems live or die by — above all lattice thermal conductivity —
but AI cannot yet design them because no transferable machine-readable representation of a
defect exists. We propose the first charge-aware, pristine-referenced defect representation,
trained across host chemistries and coupled to phonon-defect scattering models, closed against
laser-flash (LFA 457) thermal conductivity measurements, to make kappa a designable quantity.
See `lit-review/defect-representations-deep-dive.md` for evidence, alternatives, and risks.
