`projects/autonomous-corrosion-screening/`).

## Working with the agent

Open an issue or PR comment containing `@claude` and describe the task. Only
repo collaborators can trigger it. See `docs/commands-cheatsheet.md` for setup
and `CLAUDE.md` for the rules the agent follows.

Useful asks:

- `@claude Draft a timed 7-minute video script for project-a following the four ERIS elements. Read eris/eris-notes.md first.`
- `@claude Score the current project-b script against the ERIS rubric in eris/eris-notes.md and list the three weakest points.`
- `@claude Draft the four supplemental slides for project-a as a markdown outline.`
